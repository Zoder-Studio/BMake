## Bmake

the Build engine like cmame and make but more readable for human

## How To Run It

1. you need to install bmake from this repository or your system
2. generate BMake.bm using this commamd:
   ``` Bash
   bmake init
   ```
3. customize your .bm for your environment
4. after all of that, run **bmake run** to run your .bm

## Syntaxes

there are allot syntax on BMake, this are some syntaxes:

|syntaxes | for what?|
|---|---|
|Lang | use Lang for Language sistem, it is important|
|System | use System to run a spesific run engine, like gradle, cmake, make, and much more!|
|Sub-System | like System butcit is for a faster build, like ninja|
|Task | this is important because Task is for running, but its like a job, you can add multiple Task in your .bm|
